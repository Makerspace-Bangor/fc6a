######## rg_global analysis::
There’s a genuinely useful undocumented variation in this method: 
for FC6A, WindLDR does not only use P and ;. 
It selects P/; for transfer mode 0, 
but p/+ for transfer mode 1. 
That gives us two command variants we had not accounted for, 
and the code shows exactly when each is chosen.
FC6A_D16XXCEE = 0x1B

                    TransferMode 0    TransferMode 1
program data             P                 p
comment data             ;                 +

W+n   comment/supplementary data, mode 1
